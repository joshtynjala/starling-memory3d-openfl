# Memory3D for OpenFL and Haxe

This game is a simple implementation of "Memory" (also known as "Concentration") that showcases [Starling](https://github.com/openfl/starling)'s Sprite3D functionality.

Based on [PrimaryFeather/Memory3D](https://github.com/PrimaryFeather/Memory3D).

Ported to Haxe by Josh Tynjala, creator of [Feathers UI](https://feathersui.com/).
